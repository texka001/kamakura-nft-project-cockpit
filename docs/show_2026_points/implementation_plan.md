# ダッシュボードおよびポイント履歴での2026年度表示対応計画

現在、システムはデータベース（集計テーブル）に存在する最新の年度を「最新シーズン」として表示しています。2026年度のデータ（ポイント登録と集計）がまだ行われていないため、ダッシュボードには2025年度が表示されています。
ユーザーの要望に基づき、データがなくても現在のシーズン（4月1日切り替え）をデフォルトで表示し、0ポイントとして出すように修正します。

## ユーザーレビューが必要な事項
- シーズン切り替え日を **4月1日** とします。（例：2026年4月1日以降は2026年度、2026年3月31日までは2025年度）
- ダッシュボードの「最新ランク」についても、データがない場合は「-位」または「圏外」として表示されます。
- ポイント履歴ページの年度選択プルダウンに、実績がなくても現在の年度が常に出現するようになります。

## 確認計画
### 手動確認
- ログイン後、ダッシュボードの表示が「2026 Season」となり、数値が「0 pt」となっていることを確認する。
- ポイント履歴ページに移動し、シーズン選択に「2026」が表示されていること、およびそれを選択した際に0ポイントのサマリが表示されることを確認する。
- 以前の2025年度のデータも引き続き選択・閲覧できることを確認する。
