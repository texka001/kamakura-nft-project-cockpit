# 修正内容の確認 (Walkthrough) - ゴール画像の動画リンク化

ダッシュボードの「LATEST MATCH RESULTS」にあるゴールシーン画像をクリックした際、関連する動画がある場合は動画を開くように修正しました。

## 修正内容

### [ダッシュボード]
#### [page-dashboard.php](file:///Users/mukaikazuma/Desktop/AIエージェント開発/kamakura-nft-project202601/wp-content/themes/kamakura-cockpit-theme/page-dashboard.php)
- ゴールシーンの画像（`<img>`）のクリックイベントを拡張しました。
- 以下の条件で挙動が分岐します：
    - **ログイン済み ＋ 動画URLあり**: クリックで動画を別タブで開く。
    - **未ログイン ＋ 動画URLあり**: 従来通り画像拡大モーダルを開く（動画への誘導は行わない）。
    - **動画URLなし**: 従来通り画像拡大モーダルを開く。

## 検証結果

### コード確認
- 画像の `onclick` 属性に PHP の三項演算子が組み込まれ、適切な JavaScript 関数（`window.open` または `openImageModal`）が呼び出されていることを確認。

### 動作確認（期待される挙動）
- **ログイン時（動画あり）**: 画像をクリックすると動画が開く。
- **ログイン時（動画なし）**: 画像をクリックすると画像が拡大表示される。
- **未ログイン時**: 動画の有無に関わらず、画像をクリックすると画像が拡大表示される。
