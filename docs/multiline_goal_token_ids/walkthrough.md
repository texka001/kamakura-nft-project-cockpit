# ゴールトークンID登録形式の変更

「試合結果」登録画面において、ゴールごとのトークンIDを改行区切りで入力できるように変更しました。この変更により、1つのゴールに対して複数のトークンID（NFT）を紐付けることが可能になり、ダッシュボード上の表示もこれに対応しました。

## 変更内容

### 1. 管理画面の改善 (`class-kmnft-user-manager.php`)

- **UIの分かりやすさ向上**: プレースホルダーと説明文を更新し、「1行 = 1ゴール」であること、および「1点目」などの文字入力が不要であることを明示しました。
- **堅牢なデータ保存処理**: 万が一「1点目：」などの文字が入力されても、自動的に数字（と区切り文字のカンマ）のみを抽出して保存するクレンジングロジックを実装しました。

### 2. ダッシュボード表示の修正 (`page-dashboard.php`)

- **ミニマッププロット**: 改行をゴールの区切りとして正しく認識し、同一行内の複数トークンを同じゴール番号としてプロットするように修正しました。
- **ゴールバッジと動画の紐付け**: 行番号（ゴール番号）に基づき、画像バッジと対応する動画URLが正しく連動するようにしました。

## 検証結果

### ラベル付き入力の自動クリーンアップ
管理画面で `1点目：10089172280` と入力して保存すると、DBには `10089172280` として保存され、余計な文字が除去されることを確認しました。

### 既存データとの互換性
既存の改行を含まないデータも「1行目（1ゴール目）のデータ」として正しく解釈され、表示に不具合がないことを確認しました。
