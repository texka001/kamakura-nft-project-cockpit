# ダッシュボード左サイドバーの固定表示に関する修正

## 目的
PC表示において、メインコンテンツが長い場合にダッシュボードの左側サイドバーがスクロールとともに流れてしまい、下に空白ができてしまうのを防ぎます。サイドバーが見える範囲の一番下で留まる（sticky表示）ようにします。

## 変更内容
### [Theme] `kamakura-cockpit-theme`
#### [MODIFY] [page-dashboard.php](file:///Users/mukaikazuma/Desktop/AIエージェント開発/kamakura-nft-project202601/wp-content/themes/kamakura-cockpit-theme/page-dashboard.php)
- 左カラムのラッパー要素（`<div class="md:col-span-4 space-y-6">`）に、以下のTailwind CSSクラスを追加します：
    - `md:sticky`: PCサイズ以上でスティッキー配置を有効化
    - `md:top-24`: ヘッダーの高さ分（約6rem）を考慮し、上端から少し離れた位置で固定
    - `md:self-start`: フレックスアイテムとしての配置を調整
- サイドバーの内容が画面の高さを超える場合を考慮し、以下も追加します：
    - `md:max-h-[calc(100vh-8rem)]`: 高さをビューポート内に制限
    - `md:overflow-y-auto`: 内部スクロールを有効化

## 検証計画
### 手動検証
1.  **ダッシュボード表示**: PCブラウザでダッシュボードを開く。
2.  **モード確認**: ログイン状態とゲスト状態の両方で確認する（サイドバーの内容が異なるため）。
3.  **スクロール動作**: ページを下にスクロールした際、以下の挙動を確認する：
    - 左サイドバーがビューポート内に固定されて追従すること。
    - フッターやヘッダーと不自然に重ならないこと。
    - メインコンテンツが終了する位置で適切に止まるか、あるいは追従し続けること。
4.  **画面サイズ変更**: ラップトップや大画面モニターなど、異なる高さで表示崩れがないか確認。
