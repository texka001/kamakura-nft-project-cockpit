# グラウンド寸法の修正および品質改善計画

グラウンドの実寸（横102m、縦64m）に合わせてマッピング計算を修正し、全ての箇所でSVG画像を使用するように変更します。

## 変更内容

### 1. グラウンド寸法の修正 (120m → 102m)
- `page-dashboard.php` 内の全てのグラウンド表示箇所（サイドバー、試合結果、拡大モーダル）において、横幅の最大値を102に変更します。
- `aspect-ratio` を `102/64` に統一します。
- X座標のマッピング計算式を `$x / 120` から `$x / 102` に修正します。
- 座標ラベルを `(120,64)` から `(102,64)` に修正します。

### 2. モーダル内の画像差し替え
- まだ変更されていなかった拡大モーダル内のグラウンド画像を `ground_map.png` から `whiteLine.svg` に差し替えます。

## 検証計画
### 手動確認
- (102, 64) の座標を持つアセットが、グラウンドの右上端にピッタリと表示されるか確認します。
- 全ての箇所のグラウンドが歪みなく、かつ鮮明に表示されているか確認します。
