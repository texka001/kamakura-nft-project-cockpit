# グラウンド寸法の修正および品質改善計画

グラウンドの実寸（横102m、縦64m）に合わせ、さらにアセットがセルの中心に表示されるようにマッピング計算を微調整します。

## 変更内容

### 1. マッピング計算の微調整（中心点オフセット）
- 現在のアセット位置 $(X, Y)$ を、セルの中心である $(X-0.5, Y-0.5)$ として計算するように修正します。
- **修正後の計算式**:
  - `left = (($x - 0.5) / 102) * 100`
  - `bottom = (($y - 0.5) / 64) * 100`
- これにより、(1, 1) は左下から 0.5m の位置に、(102, 64) は右上端から 0.5m 内側の位置にそれぞれ正確に配置されます。

### 2. 対象箇所
- `page-dashboard.php` 内の以下の全ての表示ロジックに適用します：
  - サイドバーの `My Asset Map`
  - `LATEST MATCH RESULTS` 内のミニマップ
  - 拡大モーダル (`Map Modal`)

## 検証計画

- 全てのマッピング箇所において、表示位置が期待通りにシフトしていることを確認します。
