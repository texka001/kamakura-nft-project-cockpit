# 実装計画 - NFT詳細画像の明るさ調整

Ownedアセットをクリックした際に表示されるNFT詳細モーダルにおいて、画像が暗く見える問題を修正します。

## ユーザーレビューが必要な項目

> [!IMPORTANT]
> 画像の明るさを一律で少し上げる（10%程度）修正を含めています。これにより、暗いテーマの中でNFTがより際立つようになります。

## 提案される変更点

### テーマファイル
#### [MODIFY] [page-dashboard.php](file:///Users/mukaikazuma/Desktop/AI%E3%82%A8%E3%83%BC%E3%82%B8%E3%82%A7%E3%83%B3%E3%83%88%E9%96%8B%E7%99%BA/kamakura-nft-project202601/wp-content/themes/kamakura-cockpit-theme/page-dashboard.php)

- 画像コンテナの背景指定 `bg-black/40` を削除し、透過画像が背景の黒に引きずられないようにします。
- 画像要素（`#modal-token-image`）に `brightness-[1.1]` クラスを追加し、わずかに明るさを強調します。

## 検証計画

### 手動確認
1. ダッシュボードにログインし、「OWNED ASSETS」セクションからNFTをクリックする。
2. 表示されたモーダル内の画像が、修正前よりも明るく、クリアに見えることを確認する。
3. 画像の透過部分（角丸など）が、コンテナの背景色によって不自然に暗くなっていないことを確認する。
