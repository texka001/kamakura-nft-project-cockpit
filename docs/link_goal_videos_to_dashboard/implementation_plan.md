# 実装計画: 試合結果のゴール動画リンクの連携

ダッシュボードの「LATEST MATCH RESULTS」セクションにおいて、ゴールの位置を示すアイコン（①、②など）をクリックした際に、対応する動画URLがある場合は新しいタブで開くように実装します。

## ユーザーレビューが必要な項目
- 動画がある場合、アイコンのカーソルがポインターに変わります。
- 動画のないアイコンは従来通りの動作となります。

## 変更内容

### ダッシュボードページ ([page-dashboard.php](file:///Users/mukaikazuma/Desktop/AI%E3%82%A8%E3%83%BC%E3%82%B8%E3%82%A7%E3%83%B3%E3%83%88%E9%96%8B%E7%99%BA/kamakura-nft-project202601/wp-content/themes/kamakura-cockpit-theme/page-dashboard.php))

#### 1. データ処理の追加
各試合のループ内で、`$match->goal_videos` をパースして配列化します。

#### 2. マップ上のゴールマーカーの更新
- ②などの赤い丸のアイコンに、動画URLがある場合はクリックイベントを追加します。
- `window.open(url, '_blank')` を使用して新しいタブで開きます。

#### 3. ゴールシーン画像上のバッジの更新
- 画像左上の赤い丸のバッジに `onclick` を追加します。
- `event.stopPropagation()` を使用して、背後の画像クリックによる拡大表示（モーダル）が同時に発火しないように制御します。

## 検証計画

### 手動検証
1. 管理画面で、試合結果に動画URLを入力して保存する。
2. ダッシュボードを開き、「LATEST MATCH RESULTS」の各アイコンをクリックする。
3. 指定したURLが新しいタブで開くことを確認する。
4. 動画URLがない場合は、クリックしても悪影響がないことを確認する。
