# Excel での CSV 文字化け修正の報告

Excel で CSV ファイルを開いた際に、日本語（クラブ名など）が文字化けする問題を修正しました。

## 修正内容

### UTF-8 BOM の追加

- **ファイル**: `class-kmnft-user-manager.php`
- **内容**: CSV 出力の先頭に UTF-8 BOM (`\xEF\xBB\xBF`) を書き込む処理を追加しました。

これにより、Excel がファイルを UTF-8 として正しく認識し、文字化けせずに表示されるようになります。

## 検証結果

- `fwrite($output, "\xEF\xBB\xBF");` のコードが `fputcsv` によるヘッダー出力の前に正しく挿入されていることを確認しました。
- 修正後のファイルをデプロイし、リポジトリにプッシュしました。

## ユーザーへの確認のお願い

- 改めて順位表の CSV をダウンロードし、Excel で開いて文字化けが解消しているかご確認ください。
