# 順位表サンプルCSVダウンロード機能の追加報告

League Standings Manager において、League Schedule Manager と同様にサンプル CSV をダウンロードできる機能を追加しました。

## 実施内容

### 1. サンプルCSVダウンロードボタンの追加

- **場所**: Standings 管理画面の「CSV File」選択フィールドの下。
- **機能**: クリックすると、正しいフォーマット（ヘッダー行およびサンプルデータ）が含まれた CSV ファイルがダウンロードされます。

### 2. ダウンロード処理の実装

- **フォーマット**: Excel で開いた際の文字化けを防ぐため、UTF-8 BOM (`\xEF\xBB\xBF`) を付与しています。
- **データ内容**:
  - ヘッダー: `rank`, `clubname`, `PL`, `W`, `D`, `L`, `GD`, `PT`
  - サンプルデータとして、鎌倉インターナショナルFCを含む4チーム分のダミーデータを収録しています。

## 検証内容

- Standings 管理画面に「Download Sample CSV」ボタンが表示されていることを確認。
- ボタンクリックにより `sample_standings.csv` がダウンロードされることを確認。
- ダウンロードしたファイルが Excel で文字化けせず、正しい列構成であることを確認。
