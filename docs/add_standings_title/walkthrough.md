# 修正内容の確認：順位表に表示用タイトルを追加

順位表管理（League Standings Manager）に、各データにタイトルを付ける機能を追加しました。これにより、どの時点の順位表であるか（例：「第3節終了時点」）が分かりやすくなります。

## 変更内容

### 1. 順位表登録・編集フォームの更新
- 「Announcement Date」の下に「Display Title」入力フィールドを追加しました。
- 新規登録時および編集時にタイトルを入力・変更できます。

### 2. 保存ロジックの変更
- 入力されたタイトルをデータベースの `display_title` カラムに保存するように修正しました。

### 3. 履歴一覧テーブルの更新
- 管理画面のHistory一覧に「Display Title」列を追加し、保存されたタイトルが表示されるようにしました。

### 4. ダッシュボード表示の更新
- フロントエンド（ダッシュボード）の順位表セクションにおいて、表示用タイトルと更新日（Updated: ...）を同じ行にまとめて表示するようにしました。
- 「My Club Status」を、タイトルと順位表テーブルの間に移動しました。
- 順位表セクションの 2/3 vs 1/3 グリッドレイアウトを廃止し、順位表が画面の全幅を使えるように調整しました。
- レイアウトを縦に並べる形式に変更し、ランクとポイントをコンパクトに表示した直後に広い順位表テーブルが表示されるようにしました。
- メモ欄をテーブルの直下に移動し、より自然な流れで読めるようにしました。
- 右側カラムにあった重複する日付バッジを削除しました。

### 5. データベーススキーマの更新
- `kmnft_standings` テーブルに `display_title` カラムを自動的に追加するよう定義を更新しました。

## 確認手順

1. **Local WP** の管理画面から順位表管理ページを開きます。
2. 登録フォームに「Display Title」欄が表示されていることを確認します。
3. 適当なタイトル（例：`第1節終了時点`）を入力して順位表を保存します。
4. 下部の「History」一覧に、入力したタイトルが表示されていることを確認します。
5. 「Edit」ボタンをクリックし、タイトルが正しく読み込まれることを確認します。
