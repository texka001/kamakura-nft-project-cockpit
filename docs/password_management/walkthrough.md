# パスワード管理機能の実装 - ウォークスルー

## 概要
ログイン中のユーザー向けのパスワード変更機能と、ログインページでのパスワードリセット（「パスワードを忘れた場合」）機能を実装しました。

## 変更されたファイル
*   `wp-content/themes/kamakura-cockpit-theme/page-dashboard.php`: パスワード変更ロジックとUI（ボタン、モーダル）を追加。
*   `wp-content/themes/kamakura-cockpit-theme/page-login.php`: パスワードリセットロジックと、状態に応じたUI切り替え（ログイン、メール請求、リセット）を実装。

## 実装機能の詳細

### 1. パスワード変更（ダッシュボード）
*   **場所**: ダッシュボードの左側カラム、「Owner Profile」セクション。
*   **操作**:
    1.  「Owner Profile」内の "Change Password" リンクをクリックします。
    2.  モーダルウィンドウが表示されます。
    3.  「現在のパスワード」「新しいパスワード」「新しいパスワード（確認）」を入力し、"UPDATE PASSWORD" をクリックします。
    4.  成功すると、ページがリロードされ、プロファイル上部に緑色で成功メッセージが表示されます。失敗した場合（現在のパスワードが間違っている等）は、赤色でエラーメッセージが表示されます。

### 2. パスワードリセット（ログインページ）
*   **場所**: ログインページ下部の "Forgot Access Code?" リンク。
*   **フロー**:
    1.  **申請**: "Forgot Access Code?" をクリックすると、メールアドレス入力画面 (`?view=forgot`) に切り替わります。登録済みのメールアドレスを入力して "SEND LINK" をクリックします。
    2.  **メール受信**: システムからパスワードリセット用のリンクが記載されたメールが届きます（`wp_mail` が設定されている必要があります）。
    3.  **リセット**: メール内のリンクをクリックすると、パスワード再設定画面 (`?view=reset`) が表示されます。新しいパスワードを入力して "RESET PASSWORD" をクリックします。
    4.  **完了**: リセットが成功すると、ログイン画面に戻り、新しいパスワードでログインできることを伝えるメッセージが表示されます。

## 検証手順

### テストケース 1: ダッシュボードからのパスワード変更
1.  既存ユーザーでログインします。
2.  ダッシュボードの「Change Password」をクリックします。
3.  **異常系**: 現在のパスワードをわざと間違えて入力し、エラーメッセージが表示されるか確認します。
4.  **正常系**: 正しいパスワードと新しいパスワードを入力し、更新します。
5.  一度ログアウトし、新しいパスワードでログインできることを確認します。

### テストケース 2: パスワードリセットフロー
1.  ログアウトした状態でログインページにアクセスします。
2.  "Forgot Access Code?" をクリックします。
3.  自分のメールアドレスを入力し、送信します。
4.  **注意**: ローカル環境等でメール送信が機能しない場合、`page-login.php` のロジック内で一時的に生成されたリンクを出力するなどのデバッグが必要になる場合があります。
5.  届いたメールのリンク（またはデバッグ等の手段で取得したリンク）にアクセスします。
6.  新しいパスワードを設定します。
7.  新しいパスワードでログインできることを確認します。

## 検証時の修正対応（Troubleshooting）
検証中に以下の問題が発見され、修正を行いました。
1.  **PHPタグの入力漏れ**: `page-dashboard.php` のOwner Profileセクションで、`<?php` タグの不足によりコードがそのまま表示される問題があり、修正しました。
2.  **フッターの表示崩れ**: `page-dashboard.php` へのコード追加時に `</script>` タグ周辺の構造が崩れ、生のJavaScriptコードがフッターに表示される問題が発生しました。重複したコードブロックを削除し、`<script>` タグを整理して修正しました。
3.  **パスワード変更モーダルの表示崩れ**: モーダルの内部コンテナの `div` タグが欠落しており、スタイルが崩れていました。正しいHTML構造に修正しました。
