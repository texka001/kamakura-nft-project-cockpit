# 実装計画: ゴールシーン動画モーダルの実装

## 目的
動画が紐づいているゴールシーンを閲覧する際、すぐに動画を開くのではなく一度画像を大きく表示し、ユーザーが「動画を見る」ボタンを押すことで動画へ遷移するように改善します。これにより、ユーザー体験を向上させます。

## 変更内容

### `wp-content/themes/kamakura-cockpit-theme/page-dashboard.php`
-   **モーダルHTML構造の修正**:
    -   `#token-modal` の画像セクション内に「動画を見る」ボタン（Watch Video）のコンテナを追加します。
    -   画像コンテナに `relative` ポジショニングを適用し、ボタンをオーバーレイ表示できるようにします。
-   **JavaScript機能の追加**:
    -   新しい関数 `openGoalScene(imageUrl, videoUrl)` を実装します：
        -   既存の `openImageModal` のロジックを活用しつつ、「動画を見る」ボタンの表示制御とリンク先の設定を行います。
        -   NFT以外の画像（ゴールシーンなど）を表示する際のレイアウト調整（情報パネルの非表示）も行います。
    -   `closeTokenModal` 関数を更新し、モーダルを閉じる際に「動画を見る」ボタンも非表示にするようにします。
-   **PHPループの更新**:
    -   ゴールシーンを表示するPHPループ（870-884行目付近）を修正し、条件付きの `window.open` ではなく、新しい `openGoalScene` 関数を呼び出すように変更します。
    -   動画URLが存在する場合は関数に渡します。
    -   シーケンス番号バッジの `onclick` イベントも同様に更新します。

## 検証計画

### 手動検証
1.  **ダッシュボードを開く**:
    -   ダッシュボードページにアクセスします。
2.  **動画ありのゴールシーンを確認**:
    -   動画リンクがあるゴールシーン（通常、赤いバッジなどで識別可能）を探します。
    -   画像をクリックします。
    -   **期待される動作**: モーダルが開き、画像が大きく表示されます。「動画を見る」（Watch Video）ボタンが表示されています。
    -   「動画を見る」ボタンをクリックします。
    -   **期待される動作**: 新しいタブで動画が開きます。
3.  **動画なしのゴールシーンを確認**:
    -   動画リンクがないゴールシーンを探すか、コードを一時的に変更してシミュレートします。
    -   画像をクリックします。
    -   **期待される動作**: モーダルが開き、画像が大きく表示されます。「動画を見る」ボタンは表示されません。
4.  **NFTアセットモーダルの確認**:
    -   「Owned Assets」や「NFT Gallery」のアイテムをクリックします。
    -   **期待される動作**: アセット詳細を含むモーダルが開きます。「動画を見る」ボタンは表示されません。
