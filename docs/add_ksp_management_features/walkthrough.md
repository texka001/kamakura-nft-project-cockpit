# KSP管理機能の拡張 変更内容の確認

Token KSP管理機能の強化（日付指定削除の追加、エクスポートのフィルター対応、名称変更）を実施しました。

## 実施した変更

### 1. 削除機能の拡張と名称変更
- **Delete Token KSP (Token ID)**: 従来のトークンIDベースの削除機能の名称を、より分かりやすく変更しました。
- **Delete Token KSP (Date)** [NEW]: 指定した日付のKSPレコードをすべて削除する機能を追加しました。誤ったインポートの一括取り消しなどに利用できます。
- **Delete Token KSP (By Token ID & Date)**: 既存の個別削除機能において、入力された1行目のトークンIDが正しく認識されない不具合を修正しました。

### 2. エクスポート機能の高度化
- **フィルター追加**: `season`, `token_id`, `acquisition_date` の3つのフィルター項目を追加しました。
- **動的クエリ**: 指定されたフィルター条件に基づいてSQLを動的に構築し、必要なデータのみをCSVとしてダウンロードできるよう実装しました。
- **バリデーション追加** [NEW]: サーバー負荷軽減のため、**少なくとも1つのフィルター指定を必須**としました。すべて空で実行した場合はエラーメッセージが表示され、ダウンロードは行われません。
