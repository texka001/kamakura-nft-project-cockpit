- `page-dashboard.php`

1. ダッシュボードを開く。
2. 左上のプロジェクトロゴの下に「GAME GUIDE」という新しいボタンが表示されていることを確認する。
3. ボタンをクリックし、`https://kamakura-stadium-nft.com/shootzone/` が別タブで開くことを確認する。
