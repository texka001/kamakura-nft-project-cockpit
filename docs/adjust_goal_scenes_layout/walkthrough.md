# ウォークスルー - ダッシュボードレイアウト調整

## 変更内容

### ダッシュボード (Match Results)

**ファイル:** `page-dashboard.php`

- **タイトルの整列**: 「VS [対戦相手]」と「GOAL SCENES」のタイトルを、コンテンツグリッドの上の独立したグリッド行に配置しました。これにより、デスクトップ表示時にこれらが完全に水平に整列します。
- **画像の整列**: タイトルをコンテンツ領域から移動したことにより、グラウンドマップ画像とゴールシーン画像のグリッドが同じ高さから開始されるようになり、上端が揃いました。
- **モバイル対応**: モバイル表示では「GOAL SCENES」のタイトルを画像セクション内に表示するように調整し、自然な読み順（VS -> マップ -> GOAL SCENES -> 画像）を維持しました。

## 確認方法

1. ダッシュボードにアクセスしてください。
2. 「LATEST MATCH RESULTS」セクションを確認してください。
3. デスクトップ表示で、「VS ...」と「GOAL SCENES」が同じ高さにあること、そしてマップ画像とゴールシーン画像が同じ高さから始まっていることを確認してください。
