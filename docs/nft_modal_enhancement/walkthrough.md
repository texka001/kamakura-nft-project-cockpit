# ダッシュボード機能強化：NFT詳細表示とKSPポイント表示の統合

ダッシュボードにおけるNFTの表示を強化し、各NFTの「Season Rank」「座標」「Total KSP」を、保有資産一覧およびマップ上のプロットから直接確認できるようになりました。

## 実施内容

### 1. トークン単位のKSPデータ取得の強化
- `KMNFT_User_Manager` クラスに `get_tokens_ksp_summary` メソッドを追加し、ユーザーが保有する全NFTのKSPポイントとランクを一括で取得するようにしました。
- SQL実行時に `rank` が予約語であるための不具合を修正しました。

### 2. 「保有資産」セクションのUI更新
- 各アセットカードに「KSPポイント」と「ランク」のバッジを表示しました。
- カードをクリックすると、詳細な「トークン詳細モーダル」が開くように変更しました。

### 3. NFT詳細表示モーダルの実装 (Ported from Ranking)
- ランキングページで採用されている詳細モーダルをダッシュボードに統合しました。
- 以下の情報を美しく表示します：
    - NFT画像
    - Token ID
    - Season Rank (現在の順位)
    - 座標 (X, Y)
    - Total KSP (獲得ポイント)

### 4. マップ機能の強化
- 「保有資産マップ」（大・小両方）上の各プロット（点）をクリックすると、上記のトークン詳細モーダルが開くようになりました。
- 座標情報を持つNFTについては、詳細モーダル内で座標が表示されます。

- [x] アセットカードにポイント・ランクが正しく表示されることを確認。
- [x] カードクリックで詳細モーダルが表示されることを確認。
- [x] マップ上の点（プロット）をクリックして詳細モーダルが表示されることを確認。
