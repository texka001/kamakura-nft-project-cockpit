# 次戦ハイライトとスケジュール降順ソート

リーグスケジュール（試合日程）の表示順序を「日付の降順（新しい順）」に変更し、直近の試合（本日以降の最初の試合）をハイライト表示するようにしました。

## 変更内容

### 1. スケジュールを日付の降順にソート
- **変更前**: セクション番号順など、データの登録順または元の並び順で表示されていました。
- **変更後**: 日付（`season_year` + `date` + `time`）を基準に、**新しい日付が上**に来るように並び替えました。
    - これにより、直近の試合や未来の試合がリストの上部に表示されやすくなります。

### 2. 次戦（Next Match）のハイライト表示
- 本日以降で最も近い試合を自動的に判定します。
- **ハイライトスタイル**:
    - 行の背景色を薄い緑色 (`bg-kmnft-green/10`) に変更。
    - 左端に緑色の太いボーダー (`border-l-4 border-kmnft-green`) を追加。
    - セクション番号の横に点滅する **"NEXT"** という文字を表示。

## 検証方法

### 表示確認
1. ダッシュボードの "LEAGUE SCHEDULE / RESULTS" セクションを開きます。
2. リストが日付の降順（例: 4/20 -> 4/13 -> 4/6）で並んでいることを確認します。
3. 今日の日付（例: 2026/1/16）と比較して、次に開催される試合がハイライトされていることを確認します。
    - もし全ての試合が過去の場合、ハイライトは表示されません。
    - もし今日の試合がある場合、それがハイライトされます。
