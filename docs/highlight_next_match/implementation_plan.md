# 次戦ハイライトとスケジュール降順表示

## 目標
リーグスケジュール（試合日程）を、日付の新しい順（降順）に並べ替え、さらに「次回の試合（現在日時以降で最も近い試合）」を目立たせる（ハイライト表示する）。

## 変更内容

### フロントエンド: `page-dashboard.php`

1.  **データ処理ロジックの追加**:
    -   `$schedule_data` ループ内で、各試合データに対して `DateTime` オブジェクトを生成します（`season_year` と `date` (m/d) を使用）。
    -   **ソート**: 日付を基準に**降順**（新しい日付が上）にソートします。
    -   **次戦の特定**:
        -   現在日時（日本時間）を取得します。
        -   全試合の中から、「日付が現在または未来」かつ「最も現在に近い」試合を特定します。
        -   該当する試合の `section` または一意なIDをキーとして保持します。

2.  **表示ロジックの変更**:
    -   テーブル行（`<tr>`）の出力時に、その行が「次戦」であるかどうかを判定します。
    -   次戦の場合、行全体にハイライト用のクラス（例: `bg-kmnft-green/10`, `border-l-4 border-kmnft-green` など）を追加し、視覚的に区別します。
    -   必要に応じて "NEXT MATCH" というバッジを表示することも検討しますが、まずは行のハイライトで対応します。

## 検証計画

1.  **データ準備**:
    -   現在日付（例: 2026/1/16）に対し、過去の日付と未来の日付を含むスケジュールデータを用意します。
2.  **表示確認**:
    -   ダッシュボードを表示し、スケジュールが降順（未来の日付が上、過去の日付が下）になっていることを確認します。
    -   今日以降で直近の試合行がハイライトされていることを確認します。
