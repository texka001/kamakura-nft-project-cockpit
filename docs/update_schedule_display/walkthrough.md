# スケジュール表示の修正確認

スケジュール表示をユーザーの要望通り、昇順ソートに変更し、直近の試合結果と次の試合予定のみをデフォルトで表示するように修正しました。

## 変更内容

### [Dashboard Page](file:///Users/mukaikazuma/Desktop/AIエージェント開発/kamakura-nft-project202601/wp-content/themes/kamakura-cockpit-theme/page-dashboard.php)

- **昇順ソートの実装**:
    - 試合リストを日付の古い順（昇順）に並べ替えました。
- **直近試合・次試合の特定**:
    - 現在時刻を基準に、最も近い過去の試合を `LAST`（直近の試合結果）、最も近い未来の試合を `NEXT`（次の試合）として特定するロジックを実装しました。
- **初期表示の制御**:
    - 最新シーズンの表示において、`LAST` または `NEXT` に該当しない試合には `hidden` クラスを付与し、初期状態で非表示にしました。
    - `LAST` 試合にはグレーの左ボーダーと「LAST」ラベル、`NEXT` 試合にはグリーンの背景・左ボーダーと「NEXT」ラベル（アニメーション付き）を表示するようにしました。
- **ボタン機能の更新**:
    - 「Show Full Schedule」ボタンをクリックすることで、隠されている全ての試合を表示できるようにしました。
    - ボタンのテキストも表示状態に合わせて「Show Recent/Next Only」に切り替わるように調整しました。

## 確認事項

1.  **ソート順**: 試合が日付の昇順で表示されているか。
2.  **デフォルト表示**: 直近の試合（1件）と次の試合（1件）のみが表示されているか。
3.  **ラベル表示**: `LAST` と `NEXT` のラベルが正しく表示されているか。
4.  **折り畳み機能**: 「Show Full Schedule」ボタンで全件表示され、再度クリックで元に戻るか。

> [!NOTE]
> 過去シーズンについては、従来通りシーズンごとに折り畳まれた状態で表示されます。
