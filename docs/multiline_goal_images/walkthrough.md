# 修正内容の確認 (Walkthrough) - ゴール画像の複数行対応

ゴール画像（Goal Images）をゴールトークンIDと同様に複数行で管理し、1行につき複数の画像をカンマ区切りで入力できるように修正しました。

## 修正内容

### 1. 管理画面の入力インターフェース修正
- `Goal Images` の入力フィールドを `input type="text"` から `textarea` に変更しました。
- メディアアップローダーで画像を選択した際、既存のURLの末尾に改行して追記されるようにしました（1枚ずつ選択すると1行ずつ追加されます）。
- 複数枚を一度に選択した場合は、同一行にカンマ区切りで追加されます。

### 2. データ保存時の正規化
- 保存処理 `$process_match_save` において、入力データをパースし、各行内でのカンマ区切りURLをトリミングして空要素を除去した上で再構成するようにしました。これにより、不要な空白や改行が混入するのを防ぎます。

### 3. ダッシュボード表示ロジックの更新
- `page-dashboard.php` において、`goal_images` を行単位で分割し、さらにカンマで分割して画像リストを構築するように変更しました。
- 同じ行にある画像は同じ「ゴール番号」バッジが表示されます。
- ゴール番号（行番号）に基づき、対応するゴール動画リンクとの紐付けを維持しています。

## 検証方法

### 動作確認（管理画面）
1. 試合結果編集画面を開く。
2. 「画像を選択」ボタンで1枚画像を選ぶ -> URLがtextareaに追加される。
3. 再度「画像を選択」ボタンで別の画像を選ぶ -> URLが新しい行に追加される。
4. 手動でURLをカンマ区切りで並べる（例: `url1, url2`） -> 保存する。
5. 保存後、正規化された形式（各行1ゴール、カンマ区切り）で保持されていることを確認。

### 動作確認（ダッシュボード）
1. ダッシュボードの試合結果セクションを表示。
2. 複数画像が登録されたゴールにおいて、画像ごとに同じ番号の赤いバッジが表示されていることを確認。
3. バッジをクリックして（動画URLがある場合）正しく動画が開くことを確認。
