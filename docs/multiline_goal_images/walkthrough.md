# 修正内容の確認 (Walkthrough) - ゴール画像入力ロジックの改善

「画像を追加」ボタンをクリックした際の、textarea への追記ロジックを改善しました。

## 修正内容

### 1. 管理画面 JS の改善
- `inc/class-kmnft-user-manager.php` 内のメディアアップローダー `select` イベントを修正しました。
- 追記時に `trim()` を行わないようにし、既存の改行を保持するようにしました。
- 既存の値がある場合、末尾が改行で終わっていない限り、自動的に改行を挿入してから新しい画像を追加するようにしました。
- これにより、「画像を追加」ボタンを複数回押して画像を選択するたびに、各選択内容（ゴール）が新しい行に追記されるようになります。

## 検証結果

### 動作確認
1. 管理画面で「画像を追加」をクリック。
2. 1枚選択 -> textarea に `url1` が入る。
3. 再度「画像を追加」をクリックして1枚選択 -> **改行されて** `url2` が追加される（`url1, url2` とはならない）。
4. 2枚同時に選択 -> 同じ行にカンマ区切りで `url3, url4` が追加される。
5. 手動で改行を入れてからボタンを押す -> 不要な空行が増えず、次の行に追記される。
