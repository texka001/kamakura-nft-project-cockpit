「画像を追加」ボタンの挙動改善に加え、入力フィールドの説明文をより分かりやすく修正しました。

## 修正内容

### 1. 管理画面 JS の改善
- 「画像を追加」ボタンで画像を選択する際、既存の値があれば自動で改行を挟んでから追記するように修正しました。これにより、各「画像追加」操作が1ゴール分として自然に登録されます。

### 2. 説明文とプレースホルダーの改善
- `Goal Token IDs` の説明文とスタイルを合わせ、以下の内容に更新しました。
  > 1行につき1ゴールの画像を登録してください。1つのゴールに複数画像がある場合は、同じ行内でカンマ区切りで入力してください（「1点目」などの文字は不要です）。
  > 行の順序は Goal Token IDs の指定順と一致させる必要があります。
- プレースホルダーに具体的な入力例（`url1（1行 = 1ゴール目）` など）を追加しました。
