# リーグスケジュール表示改修（折りたたみ） 検証手順

## 変更内容
- `page-dashboard.php` を修正し、リーグスケジュールの表示を以下のように変更しました。
    1. **過去シーズン**: デフォルトで非表示。「Show All History」ボタンで切り替え。
    2. **最新シーズン**: 「NEXT」の試合がある場合、それ以外の試合をデフォルトで非表示。「Show Full Schedule」ボタンで切り替え。

## 検証手順

### 1. ダッシュボードアクセス
1. ダッシュボードの「League Schedule」エリアを確認します。

### 2. 最新シーズンの表示確認
1. **通常時（NEXTがある場合）**:
    - 「NEXT」バッジが付いた試合のみが表示されていることを確認します（またはNEXTがない場合は全表示）。
    - 表の下に「Show Full Schedule」ボタンが表示されていることを確認します。
2. **「Show Full Schedule」クリック時**:
    - ボタンをクリックすると、**そのシーズンの全試合が表示される**ことを確認します。
    - ボタンのテキストが「Show Next Match Only」に変わることを確認します。
3. **「Show Next Match Only」クリック時**:
    - もう一度クリックすると、再度**NEXTの試合のみが表示される**状態に戻ることを確認します。

### 3. 過去シーズンの表示確認
1. **通常時**:
    - 最新シーズン以外の過去のシーズンが表示されていないことを確認します。
    - エリア最下部に「Previous Seasons」ボタンが表示されていることを確認します。
2. **「Previous Seasons」クリック時**:
    - ボタンをクリックすると、過去のシーズンの**ヘッダー（SEASON 20XX）のみ**が表示されることを確認します（試合詳細は非表示）。
    - ボタンのテキストが「Hide Previous Seasons」に変わり、矢印アイコンが上向きになることを確認します。
3. **過去シーズンの展開確認**:
    - 過去シーズンのヘッダー（SEASON 20XXの行）をクリックします。
    - そのシーズンの試合一覧が表示（展開）されることを確認します。
    - ヘッダー右側の矢印アイコンが下向きから上向き（またはその逆）に変化することを確認します。
    - もう一度ヘッダーをクリックすると、試合一覧が非表示（折りたたみ）になることを確認します。
