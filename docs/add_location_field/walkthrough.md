# リーグスケジュールへの「開催場所 (Location)」項目追加

リーグスケジュール機能に、各試合の開催場所（例：鎌倉スタジアム、アウェイグラウンドなど）を管理・表示する機能を追加しました。

## 変更内容

### 1. サンプルCSVダウンロード
- **変更前**: CSVヘッダーは `Section`, `Date(m/d)`, `Time`, `Score(H - A)`, `Opponent` の5カラムでした。
- **変更後**: **`Location`** カラムを追加し、6カラム構成にしました。サンプルデータにも開催場所（例：`Kamakura Stadium`）が含まれます。

### 2. スケジュール保存処理 (バックエンド)
- CSVアップロード時、6列目のデータを「開催場所」として読み込むように修正しました。
- 読み込んだデータはJSON形式で保存され、既存の `wp_kmnft_league_schedule` テーブルに格納されます。

### 3. スケジュール表示処理 (フロントエンド)
- **ダッシュボード (League Schedule)**: テーブルに **`STADIUM`** カラムを追加しました（Opponentの右側）。
- 保存された開催場所データが表示されます。データがない場合は `-` が表示されます。

## 検証方法

### CSVの準備
1. 管理画面の「League Schedule」ページへ移動します。
2. "Download Sample CSV" ボタンをクリックし、新しいフォーマットのCSVをダウンロードします。
3. `Location`列が含まれていることを確認し、必要に応じて編集します。

### データの反映
1. 編集したCSVファイルを管理画面からアップロードし、"Save Schedule"（または "Update Schedule"）をクリックします。
2. 警告メッセージ（赤字）が表示されている通り、既存のデータは上書きされます。

### 表示確認
1. フロントエンドのダッシュボードにアクセスします。
2. "LEAGUE SCHEDULE / RESULTS" セクションを展開します。
3. テーブルに **STADIUM** 列が追加され、CSVに入力した開催場所が表示されていることを確認します。

## 注意点
- 以前のフォーマット（5カラム）のCSVをアップロードした場合、開催場所は空（`-`）として扱われます。
