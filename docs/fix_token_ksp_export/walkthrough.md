# Token KSP Export Fix & Multiple Records Support

## 概要
Token KSPのインポート機能において、データが正常に保存されず、その結果エクスポート機能で0件となる問題が発生していました。
また、同一日付・同一トークンの複数レコード登録（Enable Multiple Daily KSP）への対応も行いました。

## 変更点

### 1. データベーステーブルの作成 (`class-kmnft-user-manager.php`)
- `kmnft_token_ksp` テーブルを作成する処理 `ensure_token_ksp_table()` が欠落していたため追加しました。
- コンストラクタでこのメソッドを呼び出すようにし、テーブルが存在しない場合は自動作成されるようにしました。

### 2. インポートロジックの変更 (`class-kmnft-user-manager.php`)
- **変更前**: 同一トークン・同一日付のデータがある場合、既存レコードを更新（Update）していました。
- **変更後**: 常に新しいレコードとして挿入（Insert）するように変更しました（Append Mode）。これにより、同日に複数のポイント獲得履歴を記録できるようになりました。

### 3. デプロイと検証
- 修正コードをローカル環境にデプロイし、Gitリポジトリにコミット・プッシュを行いました。
- テストデータ `test_data/ksp_sample.csv` を生成し、インポートおよびエクスポートが正常に行えることを確認しました。

## 確認方法
1. 管理画面の「Token KSP」メニューにアクセス。
2. CSVファイルをインポートし、「Success」メッセージが表示されることを確認。
3. 「Export Token KSP」ボタンからCSVをダウンロードし、インポートしたデータが含まれていることを確認。
