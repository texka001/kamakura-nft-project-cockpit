# リーグスケジュール機能 実装確認

## 実装内容
以下の機能を実装しました。

1.  **データベース**
    - `wp_kmnft_league_schedule` テーブルの作成（シーズン、試合データ、集計データを保存）

2.  **管理画面 (バックエンド)**
    - "KMNFT Console" 下に "League Schedule" メニューを追加
    - CSVファイルアップロード機能の実装
    - シーズンごとのデータ登録・更新・削除機能
    - CSVパース処理（勝敗判定、集計処理を含む）

3.  **ダッシュボード (フロントエンド)**
    - "LEAGUE STANDINGS" セクションの下に "LEAGUE SCHEDULE / RESULTS" セクションを追加
    - シーズンごとの試合結果と集計（勝・敗・分）の表示
    - 展開/折りたたみ機能の実装

## 検証手順

### 1. 管理画面でのデータ登録
1.  WordPress管理画面にログインします。
2.  左側メニューから **KMNFT Console > League Schedule** に移動します。
3.  **Add New Schedule** フォームで以下を入力します。
    - **Season Year**: 例 `2024`
    - **CSV File**: 以下のフォーマットのCSVファイルを選択します。
      - **ヒント**: "Download Sample CSV" ボタンをクリックしてサンプルファイルをダウンロードし、それを編集して使用することをお勧めします。
      ```csv
      Section, Date(m/d), Time, Score(H - A), Opponent
      1, 4/6, 13:00, 3 - 1, イトゥアーノFC横浜
      2, 4/13, 11:00, 1 - 2, 横浜猛蹴
      ```
4.  **Save Schedule** をクリックします。
5.  **History** テーブルに登録したデータが表示され、Summary (Win-Lose-Draw) が正しく計算されていることを確認します。

### 2. ダッシュボードでの表示確認
1.  フロントエンドのダッシュボードページ (`/dashboard`) にアクセスします。
2.  "LEAGUE STANDINGS" セクションの下までスクロールします。
3.  **LEAGUE SCHEDULE / RESULTS** セクションが表示されていることを確認します。
4.  登録したシーズンのデータが正しく表示されているか確認します。
    - Win（緑色）、Lose（赤色）、Draw（灰色）の色分けが正しいか
    - データが正しくパースされているか
5.  複数のシーズンがある場合、降順（新しい順）で表示されているか確認します。

## 補足
- CSVファイルのヘッダー行は自動的にスキップされます（"Section" や "Score" が含まれる場合）。
- Scoreは "3 - 1" または "3-1" の形式に対応しています。
