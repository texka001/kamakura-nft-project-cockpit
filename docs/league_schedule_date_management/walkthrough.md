# 修正内容の確認 (Walkthrough) - 日付管理の厳密化とスケジュール表示の最適化

リーグスケジュールの管理において、西暦を含む形式（`YYYY/MM/DD` 等）への対応と、ダッシュボードでの表示の最適化を行いました。

## 実施した変更

### 1. 管理画面 (League Schedule Manager) の改善
- **説明文の更新**: CSVアップロード時の日付形式として `YYYY/MM/DD` を推奨するように説明文を修正しました。
- **サンプルデータの更新**:
    - 「サンプルCSVダウンロード」で取得できるファイルの日付形式を `YYYY/MM/DD` に変更しました。
    - 画面上の例示データも `YYYY/MM/DD` 形式に更新しました。
- **既存データダウンロードの修正**: 登録済みのスケジュールをCSVとしてダウンロードする際のヘッダーも `Date(YYYY/MM/DD)` に更新しました。

### 2. ダッシュボードの日付パースロジックの柔軟化
- **多様な形式への対応**: 以下の形式を自動判別して正しくタイムスタンプに変換します。
    - `YYYY/MM/DD`, `YYYY-MM-DD`, `YYYY/M/D` (年あり)
    - `MM/DD`, `M/D` (年なし: シーズンの年で補完)
- **判定の堅牢化**: 西暦の有無を明示的に判定し、意図しない年の誤認を防ぐロジック（`substr_count` や `preg_match` を使用）を導入しました。

### 3. スケジュール表示の最適化
- **昇順表示**: スケジュールを日付の古い順から新しい順（昇順）で表示するように変更しました。
- **主要試合の強調 (LAST / NEXT)**:
    - 現在時刻から見て「最も直近の過去の試合 (LAST)」と「最も近い未来の試合 (NEXT)」を自動特定し、強調表示します。
    - 判定にはタイムスタンプを使用しているため、日付の記述形式が混在していても正確に動作します。
- **折りたたみ表示**:
    - 最新シーズンの試合のうち、強調表示されている試合（LAST/NEXT）以外は初期状態で非表示とし、「全スケジュールを表示」ボタンで切り替え可能にしました。
    - 過去のシーズンのスケジュールは従来通り個別に展開可能です。

- [x] 昇順ソートによって、上から順に時系列で試合が並ぶことを確認。
