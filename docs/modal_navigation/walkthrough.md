# NFT詳細モーダルのナビゲーション機能追加

NFT詳細モーダルにおいて、所有しているNFTを順番に閲覧できる「前へ」「次へ」ボタンを追加しました。

## 変更内容

### 1. PHPデータのJavaScript連携
`page-dashboard.php` にて、ログインユーザーが所有するNFTの一覧データ（トークンID、ランク、ポイント、座標）をJavaScript用の配列 `ownedAssets` として書き出す処理を追加しました。

### 2. モーダルUIの更新
モーダル内の左右にナビゲーション用の矢印ボタンを追加しました。
- デザインはテーマのトーンに合わせ、ホバー時に `kmnft-green` カラーに変化します。
- 所有NFTが1つの場合はボタンは自動的に非表示になります。

### 3. JavaScriptナビゲーションロジックの追加
以下の関数を実装しました：
- `openTokenModal`: 現在表示しているNFTのインデックスを追跡するように拡張。
- `navigateToIndex`: 指定されたインデックスのNFTデータをモーダルに表示。最後のNFTから最初へ、最初から最後へのループ（ラップアラウンド）に対応。
- `prevToken` / `nextToken`: ボタンクリック時に呼び出されるナビゲーション関数。

### 4. キーボード操作サポート
より快適な操作のため、以下のキーボードショートカットを追加しました：
- `←` (左矢印キー): 前のNFTを表示
- `→` (右矢印キー): 次のNFTを表示
- `Esc` キー: モーダルを閉じる

## 確認した内容
- [x] 所有NFTが複数ある場合、ボタンが表示されること。
- [x] ボタンクリックで次の/前のNFTに正しく切り替わること。
- [x] 最後のNFTの次に最初のNFTが表示される（ループする）こと。
- [x] キーボードの左右キーで操作ができること。
- [x] 所有NFTが1つだけの場合、ボタンが表示されないこと。
