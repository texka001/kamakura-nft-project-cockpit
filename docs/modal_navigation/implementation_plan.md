# NFT詳細モーダルへのナビゲーション追加の計画

ユーザーが所有するNFTを詳細モーダル内で前後移動できるように、ナビゲーションボタン（矢印）を追加します。

## 提案される変更

### [page-dashboard.php](file:///Users/mukaikazuma/Desktop/AI%E3%82%A8%E3%83%BC%E3%82%B8%E3%82%A7%E3%83%B3%E3%83%88%E9%96%8B%E7%99%BA/kamakura-nft-project202601/wp-content/themes/kamakura-cockpit-theme/page-dashboard.php)

#### [MODIFY] データのエクスポート
- PHPの `$holdings` データをJavaScriptから利用可能な形式で `ownedAssets` 配列としてエクスポートします。
- 各アセットの `token_id`, `rank`, `points`, `x`, `y` を含めます。

#### [MODIFY] モーダルUIの変更
- `token-modal` 内に「前へ」と「次へ」のナビゲーションボタンを追加します。
- デザインは、画像の左右に浮遊する矢印アイコン、または情報の見やすい位置に配置します。今回は画像の左右に配置して、ギャラリーのように閲覧できるようにします。

#### [MODIFY] JavaScriptロジックの追加
- `openTokenModal` 関数を更新し、現在表示中のインデックスを追跡するようにします。
- `navigateToToken(index)` 関数を新規作成し、指定したインデックスのアセット情報をモーダルに反映させます。
- `prevToken()` および `nextToken()` 関数を追加して、ボタンクリック時に呼び出されるようにします。

## 検証プラン

### 手動検証
1. ダッシュボードを開き、ログインする。
2. 「OWNED ASSETS」セクションで任意のNFTをクリックして詳細モーダルを開く。
3. 新しく追加された矢印ボタンが表示されていることを確認する。
4. 「右矢印（次へ）」をクリックし、次の所有NFTの情報に切り替わることを確認する。
5. 「左矢印（前へ）」をクリックし、前の所有NFTの情報に戻ることを確認する。
6. リストの最初と最後で適切にループするか、あるいはボタンが無効化されるかを確認する（今回はループさせる仕様とします）。
